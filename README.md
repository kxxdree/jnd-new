# Joined — бары и живая музыка

Фронтенд веб-сервиса для поиска баров и музыкальных событий: фильтры по жанрам, афиша, профили заведений и групп, билеты с QR-кодом, брони столиков, кабинеты партнёров и админ-панель.

**Стек:** Nuxt 4 (Composition API, SSR) · Tailwind CSS 4 · Leaflet · qrcode

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && node .output/server/index.mjs
```

## Демо-доступ

Бэкенда нет: данные лежат в `app/data/catalog.ts`, а пользователь, билеты, брони, отзывы и избранное хранятся в cookie.
На странице `/login` есть кнопки быстрого входа под каждую роль:

| Роль | Куда попадает |
|---|---|
| Гость (пользователь) | `/account` — билеты с QR, брони, история, избранное, отзывы, уведомления |
| Бар | `/partner` — профиль заведения, мероприятия, входящие брони, фото и меню |
| Группа | `/partner` — профиль группы, концерты, треки и медиа |
| Админ | `/admin` — статистика, модерация, города, теги, пользователи, комиссии |

Оплата имитируется (`PaymentModal`), деньги не списываются.

## Структура

```
app/
  pages/            index, venues/, events/, artists/, account/, partner/, admin/, login, register, rules
  components/       карточки, фильтры, карта (VenueMap), календарь, оплата, QR, модалки
  composables/      useAuth, useCity (геолокация), useFavorites, useTickets, usePersisted, useToast
  data/             типы и моковый каталог (города, жанры, бары, артисты, события, отзывы)
  middleware/auth   защита маршрутов + проверка ролей через definePageMeta({ roles })
  assets/css        тема Tailwind (цвета, кнопки, пилюли, теги)
```

## Что заменить при подключении бэкенда

- `app/data/catalog.ts` → запросы к API через `useFetch`
- `useAuth` → настоящая авторизация (JWT/сессии)
- `useTickets` → эндпоинты покупки, возврата и бронирования
- `PaymentModal` → платёжный провайдер
- Фото: сейчас заглушки picsum.photos с фирменной тонировкой (`PhotoImg`)
- Тайлы карты: сейчас OpenStreetMap — для продакшена нужен свой провайдер (их политика запрещает высокую нагрузку)
